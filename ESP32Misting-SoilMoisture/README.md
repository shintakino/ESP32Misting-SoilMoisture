# ESP32Misting-SoilMoisture

Description: A microcontroller-based moisture sensing project with ESP32, aimed at automating plant watering based on soil moisture readings.

How to build:
- Setup toolchain for ESP32 (ESP-IDF or Arduino-ESP32) on your host
- Connect ESP32 to power and serial
- Build and flash to device

Usage:
- Read soil moisture via sensor, determine wet/dry, take action (supply water)
- Optional: integrate with MQTT or other home automation

Tests:
- Basic unit tests (logic mapping moisture to actions) can be added later
